# FreedomSMP

Minecraft FreedomSMP server assets and resources.

## Repository layout

- `resource-packs/` — FreedomSMP resource packs and custom item packs
- `map-art/` — source files for FreedomSMP map art
- `docs/` — asset documentation and usage notes

## Included assets

### Freedom Coin
`resource-packs/FreedomCoin2/` contains the Freedom Coin resource pack, including its `pack.mcmeta`, item model, and custom texture.

### FreedomSMP resource-pack collection
The uploaded collection contains:
- Colorful Trims Resource Pack
- FreedomSMP Pack v4
- Frost Armor Trim Resource Pack
- Pride Trim
- ResourcePack2
- SAT-RP v2.0
- UltimateFood

### Map art
`map-art/freedomsmpmapart1.pdn` is the Paint.NET source file for the FreedomSMP map art.

## Minecraft compatibility

Pack formats and Minecraft-version compatibility should be checked from each pack's `pack.mcmeta` before use on a live server.

## Asset policy

These files are maintained for the FreedomSMP project. Keep the original resource-pack ZIPs intact when distributing downloadable packs, and use extracted folders only when editing or inspecting pack contents.
