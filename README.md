## 🎮 Installation

### Minecraft Java Edition

1. Download the resource pack you want using one of the links above.
2. Open Minecraft Java Edition.
3. Go to **Options → Resource Packs**.
4. Select **Open Pack Folder**.
5. Place the `.zip` file directly into the resource-pack folder.
6. Return to Minecraft.
7. Move the desired pack into **Selected Resource Packs**.
8. Click **Done** and allow Minecraft to reload.

**Do not extract the ZIP unless you are editing or inspecting the pack.**

If the FreedomSMP server automatically provides the main resource pack, manual installation may not be necessary.

## ⭐ Recommended Setup

For the standard FreedomSMP experience:

1. Install **FreedomSMP Main Resource Pack** — Required.
2. Add any optional packs you want.
3. Keep the main pack enabled whenever playing on FreedomSMP.

**Main pack:** `FreedomSMPResources.zip`  
**Status:** Active  
**Version:** Latest version in this repository

Minecraft compatibility should be checked against each pack's `pack.mcmeta` and the Minecraft version currently used by FreedomSMP.

If Minecraft reports that a pack was created for a different version, check the server's supported Minecraft version before assuming the pack is incompatible.

## 🛠️ Troubleshooting

### The pack does not appear

- Make sure the file is still a `.zip`.
- Make sure it is directly inside Minecraft's resource-pack folder.
- Do not put the ZIP inside another folder.
- Restart Minecraft or reopen the Resource Packs menu.

### Textures or models are missing

Press **F3 + T** to reload resource packs. If the issue continues, download the latest version again and verify that any required optional pack is also enabled.
